# Token reconciliation - what DGA declares vs what this kit ships

Generated by `harvest/reconcile-tokens.py` against DGA stylesheet build **CYyqM6kT**.
Regenerate with `python3 harvest/reconcile-tokens.py --write`. Do not edit by hand.

`tokens.json` carries **345** values plus **67** dark, out of the custom properties
counted below. For two releases the kit explained that difference away as aliasing.
This file is the reconciliation that disproved it, regenerated from the live
stylesheet.

**Matching is by resolved value, not by name.** A declaration resolving to a literal
already present in `tokens.json` carries no value the kit is missing. That is the claim
being tested. It does **not** establish that each dropped var is a semantic duplicate -
two unrelated roles can both be `8px`.

## Verdict

**1174 of 1467** declarations resolve to a value `tokens.json` already carries. **293** do
not, so the "all aliases" reading of the gap is **wrong** and is retracted.

| The 293 that do not reconcile | Count |
|---|---|
| Generic UI-kit ramp DGA ships but does not publish as a DGA token | 246 |
| Composite of values already carried — the gradient set. Not a missing value: what is absent is the gradient *definition* | 12 |
| Unresolved expression — still holds a `var()` nothing declares. Not evidence of a missing value | 0 |
| Under DGA's dark selector, which can never match. The kit ships no dark CSS; `role.dark` is an audit-only subset | 26 |
| Excluded by name, each with its evidence (listed below) | 9 |
| **DGA-namespaced values this kit does not hold** | **0** |
| Unknown family, left for review rather than excluded | 0 |
| **To triage (the last two together)** | **0** |

The first group is a defensible exclusion — DGA's stylesheet carries the whole upstream
Untitled-UI ramp (blue, cyan, fuchsia, indigo, moss, orange, pink, purple, red, teal,
violet, yellow, and seven separate grey ramps) and the published system names 12 families.
It was never *stated* as an exclusion, which is the actual defect.

That exclusion list is **explicit, not inferred**. An earlier "anything not in the
semantic set" rule swept up `--colors-border-primary`, `--colors-text-primary` and the
`--colors-alpha-*` primitives as though they were ramp steps — and a wrong exclusion
**hides** a real gap. Anything neither evidenced-generic nor a known DGA family is left
for review and counted in the triage total, never dropped silently.

No triage entries or unresolved expressions remain. 293 declaration(s) still do
not match a carried value - the generic ramp, the composite definitions, the
inert dark declarations and the named exclusions counted above - and those are
excluded by decision, not by omission.
