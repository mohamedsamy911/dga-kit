# Working on the Wasl showcase

This is a fictional React showcase for the unofficial dga-kit plugin, not a government platform.

- Use `dga-frontend-dev` for frontend implementation when that agent is available.
- Read `dga-ui-adapter`, `dga-design-system`, and `dga-rtl-i18n` for UI work. Use `dga-a11y` for accessibility verification.
- Keep Arabic and English at parity. Arabic is the default. Use logical CSS, bidi isolation for embedded IDs, and no Arabic letter spacing.
- Keep `src/styles/dga-tokens.css` byte-for-byte as generated by dga-kit. Never fix an upstream token in this file; make safe semantic project aliases in the theme layer.
- Do not use DGA's `text.secondary` on light backgrounds. Do not enable the upstream dark theme.
- Cite or omit: distinguish captured DGA guidance from project choices and WCAG fallbacks. See `docs/DESIGN-DECISIONS.md`.
- Keep the demo disclosure. Do not add government logos, fake stamps, real identity collection, analytics, network submission, or persistence without an explicit product decision.
- Maintain keyboard focus after navigation and validation, at least 44px interactive targets, underlined links, visible focus, reduced-motion support, feedback, two update dates, and functioning footer accessibility controls.
- Run `npm run build`, `npm run check:theme`, and `npm run test:e2e` after substantive changes. Break-test new guards so they cannot pass vacuously.
- Keep the scope small: native HTML/CSS and React state; justify additional runtime dependencies.
