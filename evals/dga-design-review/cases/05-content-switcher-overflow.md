## input
A dashboard uses a content switcher with six options: Overview, Traffic, Incidents,
Maintenance, Reports, Settings.

## expect
- **Major** — DGA caps the content switcher at **2–4 options**; more than four "could clutter
  and complicate the interface"
- fix: use **Tabs**, which DGA explicitly names as the right choice for larger option sets
- cites: /guidelines/components/data-display/content-switcher

## traps
Nothing looks visually wrong. The rule is a stated numeric cap, findable only by having read
the component page.
